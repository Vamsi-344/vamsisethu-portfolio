and configured NooBaa for S3-compatible object storage. Built telemetry and
dashboarding workflows using Golang, Gin, Prometheus, and Grafana for real-time
VM and infrastructure metrics.

## Focus areas

- Rook Ceph storage operations
- S3-compatible object storage
- Prometheus metrics design
- Grafana dashboards
- Infrastructure telemetry APIs
