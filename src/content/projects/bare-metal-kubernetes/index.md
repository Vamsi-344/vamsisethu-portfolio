Built a provisioning workflow for production-grade bare-metal Kubernetes clusters.
The flow covers host preparation, network configuration, SSH hardening, iLO-driven
operations, Ansible automation, Tekton pipelines, and Kubespray-based cluster
deployment.

## Focus areas

- Repeatable cluster bootstrap
- Bare-metal host lifecycle automation
- Secure SSH and network configuration
- Pipeline-driven deployment
- Operational handoff for platform teams
